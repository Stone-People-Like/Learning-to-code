蜂巢由很多正六边形组成（如图）。现知道蜂巢中正六边形个数(n)，画出完整的形状（注意只需画一列）。


**输入格式:**

一行包含一个正整数n(1 \le n \le 10^2)，表示正六边形个数。


**输出格式:**

蜂巢形状（见样例）。


**输入样例1:**

```text
1
```


**输出样例1:**

```text
   +---+
  /     \
 +       +
  \     /
   +---+

```


**输入样例2：**

```text
2
```


**输出样例2：**

```text
   +---+
  /     \
 +       +
  \     /
   +---+
  /     \
 +       +
  \     /
   +---+
```
