杭州师范大学信息学院一年一度的C语言程序设计考试又来了！考试结束后，李华给出了自己这一学期的学习情况报告，想请你帮他预测考试结果。他用四个布尔值 a、b、c、d 分别代表（1 表示是，0 表示否） 上课是否认真听课、课后是否刷题、上课是否睡觉、考试是否作弊。作为编程高手的你打算用以下规则编写一个程序告诉他考试结果：

首先判断如果李华上课既听课又睡觉，我们则认为他的报告有误，不再考虑其他情况，直接输出 I can't help you；
如果李华考试作弊，则一定会挂科，不再考虑其他情况，直接输出 Please be honest；
如果李华既没有上课听课，也没有刷题，则输出 See you next time；
如果上述情况均不满足，输出 You're amazing!。


**输入格式:**

四个以空格分隔的整数 a、b、c、d，四个数均为 0 或 1。


**输出格式:**

一行一个字符串


**输入样例:**

```text
1 1 0 0
```


**输出样例:**

```text
You're amazing!
```
