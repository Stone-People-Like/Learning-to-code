汉诺塔，又称河内塔，是一个益智玩具。圆盘从下面开始按大小顺序重新摆放在另一根柱子上。并且规定，在小圆盘上不能放大圆盘，在三根柱子之间一次只能移动一个圆盘。”
大家都知道，河内之塔是一道经典的递归题目，经过博哥的仔细推算，将n块圆盘按照要求移动到另一根柱子上的次数为2^n-1。假如说移动一次需要一秒，那按照要求移动n块圆盘需要多久呢？

输入格式：
一个整数n(1 \leq n \leq 30)
输出格式：
四个整数a，b，c，d， 中间用空格隔开。分别表示日，时，分，秒。


输入样例1

```text
3
```

输出样例1

```text
0 0 0 7
```

输入样例2

```text
20
```

输出样例2

```text
12 3 16 15
```

输入样例3

```text
1
```

输出样例3

```text
0 0 0 1
```

输入样例4

```text
30
```

输出样例4

```text
12427 13 37 3
```
