我们定义一个由三个自然数 a, b, c\ (a < b < c) 组成，并满足 a^2+b^2=c^2 的三元组为美丽三元组，例如 3^2+4^2=5^2 。
现给定一个正整数 n ，求满足 a + b + c = n 并且是美丽三元组的数量，若不存在这样的三元组则输出 No Joyfine ，如果答案唯一则输出这个三元组中三个数的乘积，即 a\times b \times c ，如果有超过一个美丽三元组满足条件，则输出满足 Many 和这个三元组的数量，例如 Many 6 。


**输入格式:**

一个正整数 n\ (12\leq n \leq 2.5\times10^3)，n 的意义见题目描述。


**输出格式:**

一个整数或者一句话，意义见题目描述。


**输入样例1:**

```text
1000
```


**输出样例1:**

```text
31875000
```


**输入样例2:**

```text
999
```


**输出样例2:**

```text
No Joyfine
```


**输入样例3:**

```text
90
```


**输出样例3:**

```text
Many 2
```
