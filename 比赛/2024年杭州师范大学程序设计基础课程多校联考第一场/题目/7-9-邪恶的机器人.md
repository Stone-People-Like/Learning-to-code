小慧有一台友好的机器人，每次可以受小慧随意遥控从(x,y) 移动到(x,y-1),(x,y+1),(x+1,y),(x-1,y)这四个位置的其中一个但是有一天这个机器人产生了自我意识变得十分邪恶，无论小慧怎么控制，这台机器人每次操作只能从(x,y)走到(x+1,y+1)或者(x-2,y)，不过这两种走法走哪种还是小慧能够决定的，今天她邀请你玩这台机器人，希望你能尝试用最少的步数从(a,b)走到(c,d)。


**输入格式:**

一行包含四个整数a，b，c，d，(a,b)表示起点坐标，(c,d)表示终点坐标。（-1000\le a,b,c,d\le 1000）


**输出格式:**

一个整数表示最小步数或者无法到达输出-1。


**输入样例1:**

```text
0 0 1 1 
```


**输出样例1:**

```text
1
```


**输入样例2:**

```text
0 0 -2 0
```


**输出样例2:**

```text
1
```
