# P1246 [ECNA 1995] 编码

## 题目描述

编码工作常被运用于密文或压缩传输。这里我们用一种最简单的编码方式进行编码：把一些有规律的单词编成数字。

一个“特殊单词”满足以下条件：

- 仅由 $26$ 个小写字母（$\mathtt{a,b,c,\cdots,z}$）组成；
- 长度在 $1$ 到 $6$ 之间；
- 字母严格递增。

将所有特殊单词按如下顺序排列：

1. 按单词长度从小到大排列；
2. 长度相同的单词，按字典序排列。

从 $1$ 开始依次编号，一个特殊单词的编码就是它在上述排列中的位置。

例如：

- $\mathtt a \to 1$；
- $\mathtt b \to 2$；
- $\mathtt z \to 26$；
- $\mathtt {ab} \to 27$；
- $\mathtt {ac} \to 28$。

你的任务是：对于给定的单词，求出它的编码。

## 输入格式

仅一行，一个字符串，表示被编码的单词。

## 输出格式

仅一行，一个整数，表示对应的编码。如果单词不是特殊单词，则输出 $0$。

## 输入输出样例 #1

### 输入 #1

```
ab

```

### 输出 #1

```
27

```
