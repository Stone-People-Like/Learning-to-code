# Learning to Code

> 两人协作的编程学习仓库 — 记录成长，共享知识

## 简介

本仓库由两位学习者共同维护，用于记录编程学习的过程、笔记与项目实践。`main` 分支存放共用的学习资料，各自的学习记录则放在独立的个人分支中。

## 分支结构

| 分支 | 说明 | 维护者 |
|------|------|--------|
| `main` | 公共学习资料、共享笔记与资源 | 共同维护 |
| `Stone-code` | 个人学习记录与代码练习 | Stone |
| `Waking-code` | 个人学习记录与代码练习 | Waking |

## 目录规划

```
Learning-to-code/
├── README.md            # 本文件
├── notes/               # 公共学习笔记
├── exercises/           # 代码练习
└── projects/            # 项目实践
```

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/Stone-People-Like/Learning-to-code.git
cd Learning-to-code

# 切换到你的个人分支
git checkout Stone-code    # 或 Waking-code

# 开始记录你的学习旅程
```

## 协作约定

- **公共资料** 统一放在 `main` 分支，提交前互相确认
- **个人分支** 可自由管理，记录自己的笔记、练习和项目
- 提交信息使用简洁明了的描述，例如：`添加 Python 基础笔记`
- 遵守友好协作原则，尊重彼此的代码和内容
