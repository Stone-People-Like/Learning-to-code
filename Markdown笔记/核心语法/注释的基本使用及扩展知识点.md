# 注释的基本使用及扩展知识点

- 基本使用

  - 单行注释

    以`//`开始后面的文本内容注释，程序不会执行

    举例说明：

    ```c
    // 我是注释内容
    ```

  - 多行注释

    以`/*`为开头`*/`为结尾中间的内容为注释文本，程序不会执行

    ```c
    /* 我是注释 */
    ```

- 扩展知识点

  1. 注释的快捷键

     在一般的编辑器中，单行注释一般为：`Ctrl + /`  多行注释一般为：`Ctrl + Shift + /` 

  2. 注释擦除

     注释的内容，不参与运行。在编译的obj文件内容是没有注释显示的

     > [!NOTE]
     >
     > 建议：注释的内容只跟写的代码有关，不要写无关内容

  3. 注释的嵌套

     一行内有多个当行注释没有什么影响，但是多行注释内嵌套多行注释会导致编译器只认识最近的注释导致注释语法报错

     > [!NOTE]
     >
     > 建议：注释不要进行嵌套操作
