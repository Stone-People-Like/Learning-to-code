# 整数类型

- 整数类型的定义方法

  - 基本格式

    类型说明符 + 变量名，后面可以跟初始值

    ```c
    int a = 10;    // 定义并初始化
    int b;         // 只定义
    b = 10;        // 再赋值，同样合法
    ```

  - 五种基本整数类型

    | 类型 | 说明 | 后缀 |
    |------|------|------|
    | `char` | 字符型，本质是最小的整数 | 无 |
    | `short` | 短整型 | 无 |
    | `int` | 整型，日常最常用 | 无 |
    | `long` | 长整型 | `L`，如 `1000L` |
    | `long long` | 更长的整型（C99） | `LL`，如 `1000LL` |

    举例说明：

    ```c
    char      c  = 'A';
    short     s  = 100;
    int       i  = 1000;
    long      l  = 1000L;
    long long ll = 1000LL;
    ```

  - 符号修饰符

    `signed` 表示有符号（可正可负），是默认值，可以省略；`unsigned` 表示无符号（只能非负）

    ```c
    signed int   si = -100;   // 等价于 int si = -100;
    unsigned int ui = 100U;
    unsigned char uc = 255;   // 无符号 char 最大就是 255
    ```

    > [!NOTE]
    >
    > 建议：局部变量一定要初始化。不初始化时，它的值是内存里的随机垃圾，不是 0

- 用 sizeof 测量本机的数据类型大小

  - sizeof 是运算符

    `sizeof` 不是函数，编译阶段就能算出结果，括号里既可以写类型名，也可以写变量名

    ```c
    sizeof(int)    // 接类型名
    sizeof(a)      // 接变量，结果一样
    ```

  - 返回类型是 size_t

    `sizeof` 的返回值类型是 `size_t`，不是 `int`，所以格式符要用 `%zu`

    ```c
    printf("%zu\n", sizeof(int));
    printf("%zu\n", sizeof(a));
    ```

  - 典型结果（单位：字节）

    | 类型 | Windows x64 (LLP64) | Linux/macOS x64 (LP64) |
    |------|------|------|
    | `char` | 1 | 1 |
    | `short` | 2 | 2 |
    | `int` | 4 | 4 |
    | `long` | **4** | **8** |
    | `long long` | 8 | 8 |

    举例说明：

    ```c
    printf("sizeof(char)      = %zu\n", sizeof(char));
    printf("sizeof(short)     = %zu\n", sizeof(short));
    printf("sizeof(int)       = %zu\n", sizeof(int));
    printf("sizeof(long)      = %zu\n", sizeof(long));
    printf("sizeof(long long) = %zu\n", sizeof(long long));
    ```

- 扩展知识点

  1. 不要用 `%d` 打印 `sizeof`

     `%d` 读的是 4 字节的 `int`，而 `sizeof` 返回 8 字节的 `size_t`，类型不匹配属于未定义行为。数值小时可能"碰巧"打印正确，一旦超过 2³¹ 就会出错

     > [!NOTE]
     > 
     > 建议：打印 `sizeof` 一律用 `%zu`

  2. `long` 的宽度不固定

     `long` 在 Windows 上是 4 字节，在 Linux 64 位上是 8 字节。`printf("%ld", l)` 两边都匹配，但不能假设它到底是几个字节

  3. 需要固定宽度时用 stdint.h

     `int8_t`、`int16_t`、`int32_t`、`int64_t` 在不同平台上的宽度是固定的

     ```c
     #include <stdint.h>
     int32_t x = 100;    // 一定占 4 字节
     ```

  4. 用 limits.h 查看取值范围

     `sizeof` 只能告诉你占几个字节，想知道能存多大，要查 `<limits.h>` 里的宏

     ```c
     #include <limits.h>
     printf("%d ~ %d\n", INT_MIN, INT_MAX);
     printf("%ld ~ %ld\n", LONG_MIN, LONG_MAX);
     ```
