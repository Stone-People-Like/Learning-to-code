# 浮点类型

- 浮点类型的定义方法

  - 基本格式

    和整数一样：类型说明符 + 变量名，后面可以跟初始值

    ```c
    float  f = 3.14f;    // 定义并初始化
    double d;            // 只定义
    d = 3.14;            // 再赋值
    ```

  - 三种浮点类型

    | 类型 | 说明 | 后缀 | 典型大小 | 有效数字 |
    |------|------|------|---------|---------|
    | `float` | 单精度 | `f` 或 `F` | 4 字节 | 6~7 位 |
    | `double` | 双精度，默认类型 | 无 | 8 字节 | 15~16 位 |
    | `long double` | 长双精度 | `l` 或 `L` | 平台相关 | 平台相关 |

    举例说明：

    ```c
    float       f  = 3.14f;
    double      d  = 3.14;
    long double ld = 3.14L;
    ```

  - 后缀不能省

    小数常量**默认是 `double`**。把 `3.14` 赋给 `float` 变量会发生隐式转换（精度可能损失），编译器一般会给出警告

    ```c
    float f = 3.14;    // 有警告：double 转 float
    float g = 3.14f;   // 正确写法
    ```

  - 科学计数法

    `e` 或 `E` 后面跟指数，`1.5e3` 就是 `1.5 × 10³ = 1500.0`

    ```c
    double sci = 1.5e3;    // 1500.0
    double dec = 1500.0;   // 完全等价
    ```

- 用 sizeof 测量本机的数据类型大小

  - 典型结果（单位：字节）

    | 类型 | Windows x64 (MSVC) | Linux x64 (GCC) |
    |------|------|------|
    | `float` | 4 | 4 |
    | `double` | 8 | 8 |
    | `long double` | **8** | **16** |

    举例说明：

    ```c
    printf("sizeof(float)       = %zu\n", sizeof(float));
    printf("sizeof(double)      = %zu\n", sizeof(double));
    printf("sizeof(long double) = %zu\n", sizeof(long double));
    ```

    > [!NOTE]
    >
    > 注意：MSVC 的 `long double` 只有 8 字节，精度和 `double` 完全一样，是个「名义上的」长双精度

  - 打印用的格式符

    | 格式符 | 用途 |
    |------|------|
    | `%f` | 打印 `float` 和 `double`（`float` 会自动提升为 `double`） |
    | `%Lf` | 打印 `long double`，**L 不能省** |
    | `%e` | 科学计数法 |
    | `%g` | 自动选择 `%f` 或 `%e`，去掉多余的 0 |

    ```c
    printf("%f\n", 3.14);      // 默认保留 6 位小数
    printf("%.2f\n", 3.14159); // 指定保留 2 位
    printf("%Lf\n", 3.14L);
    ```

- 扩展知识点

  1. scanf 的格式符必须严格对应

     `scanf` 需要知道变量有多大才能写对内存，所以三个类型不能混用

     ```c
     float       f;
     double      d;
     long double ld;
     scanf("%f",  &f);    // float
     scanf("%lf", &d);    // double，l 不能省
     scanf("%Lf", &ld);   // long double，L 不能省
     ```

     > [!NOTE]
     > 
     > 建议：`printf` 里 `%f` 能打印 `double`，但 `scanf` 里 `%f` 只能读 `float`，两者规则不一样

  2. 0.1 + 0.2 不等于 0.3

     计算机用二进制存浮点数，`0.1`、`0.2` 这类十进制小数无法精确表示，只能存近似值，相加后误差就显现出来了

     ```c
     printf("%.20f\n", 0.1 + 0.2);    // 0.30000000000000004441
     ```

  3. 比较浮点数不能用 ==

     正确做法是判断两个数的差值是否小于一个足够小的数

     ```c
     double a = 0.1 + 0.2;
     double b = 0.3;
     double diff = a - b;
     if (diff < 0) diff = -diff;
     if (diff < 1e-9) {
         // 认为相等
     }
     ```

  4. 整数除法会截断

     两个整数相除，结果还是整数，小数部分直接丢掉

     ```c
     printf("%d\n", 5 / 2);      // 2，不是 2.5
     printf("%f\n", 5 / 2.0);    // 2.500000，有一边是浮点才行
     ```

  5. 用 float.h 查精度和范围

     ```c
     #include <float.h>
     printf("%d\n", FLT_DIG);     // float 的有效数字位数
     printf("%e\n", FLT_MAX);     // float 能表示的最大值
     ```
