# 字符类型

- 字符的定义方法

  - 基本格式

    用**单引号**括起来的一个字符，类型是 `char`，占 1 字节

    ```c
    char c     = 'A';    // 定义并初始化
    char digit = '5';    // 注意这是字符 '5'，不是数字 5
    char ch;             // 只定义
    ch = 'x';            // 再赋值
    ```

  - 单引号 vs 双引号

    | 写法 | 类型 | 含义 |
    |------|------|------|
    | `'A'` | `char`（实际是 `int`，见下文） | 一个字符 |
    | `"A"` | `char[2]` | 字符串，`'A'` 加上结尾的 `'\0'` |

    ```c
    printf("%zu\n", sizeof('A'));    // C 里是 4，因为字符常量类型是 int
    printf("%zu\n", sizeof("A"));    // 2，一个字符加一个 '\0'
    ```

  - 转义字符

    有些字符没法直接打出来，用反斜杠开头表示

    | 转义 | 含义 | 码值 |
    |------|------|------|
    | `\n` | 换行 | 10 |
    | `\t` | 制表符 | 9 |
    | `\r` | 回车 | 13 |
    | `\0` | 空字符，字符串结束标志 | 0 |
    | `\\` | 反斜杠本身 | 92 |
    | `\'` | 单引号 | 39 |
    | `\"` | 双引号 | 34 |
    | `\a` | 响铃 | 7 |
    | `\b` | 退格 | 8 |

    ```c
    printf("第一行\n第二行\n");
    printf("A\tB\tC\n");
    printf("反斜杠：\\\n");
    ```

- 字符的本质是整数

  - ASCII 码值

    每个字符都对应一个编号，`char` 实际上就是 1 字节的整数

    | 字符 | 码值 | 备注 |
    |------|------|------|
    | `'\0'` | 0 | 字符串结束标志 |
    | `'0'` ~ `'9'` | 48 ~ 57 | 数字字符是连续的 |
    | `'A'` ~ `'Z'` | 65 ~ 90 | 大写字母是连续的 |
    | `'a'` ~ `'z'` | 97 ~ 122 | 小写字母是连续的 |
    | `' '` | 32 | 空格 |

    大小写字母的码值正好相差 **32**，所以 `'a' - 'A' == 32`

  - %c 和 %d

    同一个 `char` 变量，用 `%c` 打印出字符，用 `%d` 打印出码值

    ```c
    char c = 'A';
    printf("%c\n", c);    // A
    printf("%d\n", c);    // 65
    ```

  - 字符和数字互相转换

    数字字符减去 `'0'` 就得到真正的数字，这是处理输入时最常用的技巧

    ```c
    char digit = '5';
    int  n = digit - '0';        // 5
    char back = n + '0';         // '5'
    ```

  - 大小写转换

    ```c
    char lower = 'A' + 32;       // 'a'
    char upper = 'a' - 32;       // 'A'
    ```

- 用 sizeof 测量

  - 典型结果

    | 写法 | 结果 | 说明 |
    |------|------|------|
    | `sizeof(char)` | 1 | 标准规定就是 1 字节 |
    | `sizeof('A')` | **4** | C 里字符常量的类型是 `int`，不是 `char` |
    | `sizeof("A")` | 2 | 字符串多一个 `'\0'` |

    > [!NOTE]
    >
    > 注意：`sizeof('A')` 在 C 里是 4，在 C++ 里是 1。这是 C 和 C++ 的一个经典差异

- 扩展知识点

  1. char 到底有没有符号

     `char` 是否等价于 `signed char` 由编译器决定，标准没有规定。要明确就用带前缀的写法

     ```c
     signed char   sc;    // -128 ~ 127
     unsigned char uc;    // 0 ~ 255
     ```

     `unsigned char` 常用来处理字节数据，因为不会出现负数

  2. 汉字存不进 char

     一个 `char` 只有 1 字节，而汉字在 UTF-8 下占 3 字节，在 GBK 下占 2 字节，都放不下

     ```c
     char c = '中';    // 错误：多字符常量，行为由实现决定
     ```

  3. 用 ctype.h 判断字符类型

     ```c
     #include <ctype.h>
     isdigit('5');    // 是不是数字字符
     isalpha('a');    // 是不是字母
     isupper('A');    // 是不是大写
     toupper('a');    // 转大写，返回 'A'
     tolower('A');    // 转小写，返回 'a'
     ```

     > [!NOTE]
     > 
     > 建议：`toupper` / `tolower` 只对字母有效，其他字符原样返回

  4. 字符数组才是字符串

     单个 `char` 只能存一个字符，要存一串字符得用数组

     ```c
     char str[] = "hello";    // 6 个字节，结尾自动加 '\0'
     ```

     这也是为什么 `"A"` 占 2 字节：字符本身 + 结束标志
