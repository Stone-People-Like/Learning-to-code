# 键盘录入

- scanf 的基本用法

  - 基本格式

    ```c
    scanf("格式串", &变量);
    ```

    `scanf` 从键盘读取数据，按格式串的说明解析，再存进变量

    ```c
    int age;
    scanf("%d", &age);    // 输入 20，age 就变成 20
    ```

  - 为什么必须加 &

    `scanf` 需要知道**把数据写到哪个内存地址**，所以传的是变量的地址，不是变量的值。少了 `&` 就是把值当成地址用，程序会直接崩溃

    ```c
    scanf("%d", age);     // ❌ 少了 &，崩溃
    scanf("%d", &age);    // ✅ 正确
    ```

    > [!NOTE]
    >
    > 例外：字符数组（字符串）的数组名本身就是地址，不用加 `&`

- 格式符对照表

  | 数据类型 | 格式符 | 示例 |
  |------|------|------|
  | `int` | `%d` | `scanf("%d", &n);` |
  | `unsigned int` | `%u` | `scanf("%u", &n);` |
  | `long` | `%ld` | `scanf("%ld", &n);` |
  | `long long` | `%lld` | `scanf("%lld", &n);` |
  | `float` | `%f` | `scanf("%f", &f);` |
  | `double` | `%lf` | `scanf("%lf", &d);` |
  | `long double` | `%Lf` | `scanf("%Lf", &ld);` |
  | `char` | `%c` | `scanf("%c", &c);` |
  | 字符串 | `%s` | `scanf("%s", name);` |
  | 十六进制 | `%x` | `scanf("%x", &n);` |
  | 八进制 | `%o` | `scanf("%o", &n);` |

  > [!NOTE]
  >
  > 注意：`printf` 里 `double` 用 `%f` 就行，但 `scanf` 里 `double` **必须**用 `%lf`，两者的规则不一样

- 一次输入多个值

  ```c
  int a, b;
  scanf("%d %d", &a, &b);    // 输入 3 5，a=3, b=5
  ```

  用空格分隔时，实际输入的空格、Tab、回车都算分隔符，输入 `3      5` 也没问题

- 字符输入的换行符陷阱

  - 问题

    `%c` 会**老老实实读一个字符**，包括空格和回车。前面如果用 `scanf("%d")` 读过数字，按下的回车还留在缓冲区里，会被 `%c` 直接读走

    ```c
    int n; char c;
    scanf("%d", &n);     // 输入 5 然后按回车
    scanf("%c", &c);     // c 读到的是 '\n'，不是你以为的字符
    ```

  - 解决办法一：%c 前加空格

    ```c
    scanf(" %c", &c);    // 空格表示「跳过所有空白字符」
    ```

  - 解决办法二：手动吃掉换行

    ```c
    getchar();           // 读走缓冲区里的 '\n'
    scanf("%c", &c);
    ```

- 字符串输入

  - %s 遇到空格就停

    ```c
    char name[20];
    scanf("%s", name);    // 输入 "Li Ming"，只会读到 "Li"
    ```

  - 数组名不用加 &

    ```c
    scanf("%s", name);     // ✅ 数组名就是地址
    scanf("%s", &name);    // ❌ 类型不对，虽然常常侥幸能跑
    ```

  - 读整行用 fgets

    ```c
    char line[100];
    fgets(line, sizeof(line), stdin);    // 可以读空格，包含换行符
    ```

- scanf 的返回值

  返回值是**成功读到的项数**，可以用来判断输入是否合法

  | 返回值 | 含义 |
  |------|------|
  | 等于参数个数 | 全部读取成功 |
  | 小于参数个数 | 中间某项格式不匹配，停止了 |
  | `0` | 第一个就不匹配 |
  | `EOF`（-1） | 输入结束或出错 |

  ```c
  int n;
  if (scanf("%d", &n) != 1) {
      printf("输入的不是整数\n");
  }
  ```

- 常见错误

  | 错误写法 | 后果 |
  |------|------|
  | `scanf("%d", n)` | 少了 `&`，崩溃或写入随机内存 |
  | `double` 用 `%f` | 只写 4 字节，值完全错误 |
  | `float` 用 `%lf` | 越界写 8 字节，破坏相邻内存 |
  | `%c` 前不加空格 | 读到上一次残留的 `\n` |
  | `%s` 不限制长度 | 输入超长导致缓冲区溢出 |

- 扩展知识点

  1. 输入分隔符

     `scanf` 用空白字符（空格、Tab、回车）作为默认分隔符，所以 `scanf("%d%d", &a, &b)` 也能正常工作

  2. gets 已经被废弃

     `gets` 不检查长度，是著名的安全漏洞来源，C11 已经把它从标准里删掉，一律改用 `fgets`

  3. 缓冲区

     键盘输入先进入缓冲区，`scanf` 从缓冲区取数据。取剩下的内容会留给下一次读取，这就是 `%c` 陷阱的根源
