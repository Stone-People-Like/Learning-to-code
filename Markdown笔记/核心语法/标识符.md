# 标识符

- 什么是标识符

  - 定义

    标识符就是程序员自己起的名字，用来标记变量、函数、宏、结构体、数组等

    ```c
    int  studentAge = 20;    // studentAge 是标识符
    int  add(int a, int b);  // add、a、b 都是标识符
    #define MAX_SIZE 100     // MAX_SIZE 也是标识符
    ```

- 命名规则

  这些是**语法规则**，违反任何一条都会直接编译报错

  - 只能由字母、数字、下划线组成

    ```c
    int student_age = 1;    // 合法
    int my-var = 1;         // 非法：减号不合法
    int my var = 1;         // 非法：不能有空格
    ```

  - 不能以数字开头

    ```c
    int count2 = 1;         // 合法：数字在末尾
    int 2count = 1;         // 非法：数字开头
    ```

  - 区分大小写

    ```c
    int age = 18;
    int Age = 30;
    int AGE = 40;           // 这是三个不同的变量
    ```

  - 不能是关键字

    关键字是编译器保留的，不能拿来当名字

    ```c
    int int = 0;            // 非法：int 是关键字
    int Int = 0;            // 合法：Int 不是关键字（但别这么写）
    ```

  - 长度限制

    C99 保证至少支持 63 个有效字符（内部标识符 31 个），现代编译器实际支持得更长，但没必要起很长

- 合法与非法对照

  | 标识符 | 是否合法 | 原因 |
  |------|------|------|
  | `studentAge` | ✅ | 字母开头，只含字母 |
  | `student_age` | ✅ | 下划线是合法字符 |
  | `count2` | ✅ | 数字可以出现在中间或末尾 |
  | `_temp` | ✅ | 下划线开头合法（但不建议） |
  | `MAX_SIZE` | ✅ | 全大写合法，习惯留给宏 |
  | `2count` | ❌ | 数字开头 |
  | `my-var` | ❌ | 含减号 |
  | `my var` | ❌ | 含空格 |
  | `int` | ❌ | 是关键字 |
  | `中文变量` | ⚠️ | 部分编译器支持，不推荐 |

- 关键字

  关键字是 C 语言自带的、有特殊含义的标识符，**全部小写**

  - C89 的 32 个关键字

    | 分类 | 关键字 |
    |------|------|
    | 数据类型 | `char` `short` `int` `long` `float` `double` `void` `signed` `unsigned` |
    | 类型限定 | `const` `volatile` |
    | 存储类 | `auto` `static` `extern` `register` `typedef` |
    | 流程控制 | `if` `else` `switch` `case` `default` `for` `while` `do` `break` `continue` `goto` `return` |
    | 构造类型 | `struct` `union` `enum` |
    | 其他 | `sizeof` |

  - C99 新增的 5 个

    `_Bool` `_Complex` `_Imaginary` `inline` `restrict`

  - 顺带一提

    `main`、`printf`、`sizeof` 里只有 `sizeof` 是关键字，`main` 和 `printf` 都是普通标识符，只是标准规定了它们的含义

- 命名规范

  这些不是语法要求，违反不会报错，但会影响代码可读性

  1. 见名知意

     ```c
     int a = 20;         // ❌ 不知道 a 是什么
     int studentAge = 20; // ✅ 一看就懂
     ```

  2. 风格统一

     同一份代码里不要混用两种风格

     ```c
     int studentAge;      // 驼峰：变量名首字母小写
     int student_age;     // 下划线：单词之间用 _
     ```

  3. 宏用全大写

     ```c
     #define MAX_SIZE 100
     ```

  4. 循环变量可以用短名字

     `i`、`j`、`k` 作为循环变量是业界通用的例外

  5. 不要以下划线开头

     以下划线开头的标识符部分被标准保留给编译器实现使用，容易撞名

  6. 不要和标准库函数重名

     自己定义 `printf`、`scanf`、`malloc` 会导致行为异常

     > [!NOTE]
     > 
     > 建议：名字长度和清晰度要平衡，`i` 可以，`a` 不行，`theNumberOfStudentsInClass` 又太长

- 扩展知识点

  1. 标识符的作用域

     同一个名字在不同作用域里可以重复定义，`{}` 内部的就是局部作用域

     ```c
     int a = 1;
     void f() {
         int a = 2;    // 合法，这是另一个 a
     }
     ```

  2. 标识符和变量的区别

     标识符是「名字」，变量是「名字 + 类型 + 存储空间」。一个标识符可以标记变量、函数、类型等多种实体

  3. 命名风格没有标准答案

     Linux 内核用下划线，Windows API 用驼峰。团队统一比选哪种更重要
