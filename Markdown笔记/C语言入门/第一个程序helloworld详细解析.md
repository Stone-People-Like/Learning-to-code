# 第一个程序helloworld详细解析





```c
##include <stdio.h>

int main() 
{
	printf("%s","HelloWord!");
	return 0;
}
```

#### 每行的代码解析

| 1    | `#include <stdio.h>`         | 预处理指令，包含标准输入输出头文件 `stdio.h`。它提供了 `printf` 等函数的声明，让编译器知道 `printf` 怎么用。 |
| ---- | ---------------------------- | ------------------------------------------------------------ |
| 2    | `int main()`                 | 定义主函数 `main`。`main` 是 C 程序的入口，程序运行时从这里开始执行。`int` 表示它执行完后会返回一个整数给操作系统。 |
| 3    | `{`                          | 主函数体开始。                                               |
| 4    | `printf("%s","HelloWord!");` | 调用 `printf` 函数输出内容。`"%s"` 是格式字符串，表示“这里要输出一个字符串”；第二个参数 `"HelloWord!"` 就是要输出的字符串。最终屏幕上显示 `HelloWord!`。 |
| 5    | `return 0;`                  | 从 `main` 函数返回整数 `0`。通常 `0` 表示程序成功执行、正常结束。 |
| 6    | `}`                          | 主函数体结束。                                               |
