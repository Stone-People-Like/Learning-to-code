# `Java` 当中的数据类型区别

## 整数类型

| 整数    | 取值范围                                   | 内存占用(字节) |
| ------- | ------------------------------------------ | -------------- |
| `byte`  | -128 ～127                                 | 1              |
| `short` | -32768 ～32767                             | 2              |
| `int`   | -2147483648 ～2147483647                   | 4              |
| `long`  | -9223372036854775808 ～9223372036854775807 | 8              |

适用于严格控制内存使用量的情况否则还是 `long` 使用的多

## 浮点数类型

| 小数     | 取值范围                          | 内存占用(字节) |
| -------- | --------------------------------- | -------------- |
| `float`  | -3.402*10 的38 次 ~ 3.402*10 的38 | 4              |
| `double` |                                   | 8              |

## 字符类型

| 字符   | 内存占用(字节) |
| ------ | -------------- |
| `char` | 2              |

## 布尔类型

| 布尔      | 内存占用(字节) |
| --------- | -------------- |
| `boolean` | 1              |
