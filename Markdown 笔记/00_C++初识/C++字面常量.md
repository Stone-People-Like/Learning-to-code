# C++字面常量

## 数值型常量

- 整型字面常量

  ```C++
  int main(){ //都是整数
   21;
   23;
   34;
  }
  ```

- 实型字面常量

  ```C++
  int main(){ 	//都是小数
   2.34;
   3.14;
   23.4;
  }
  ```

## 字符型字面常量

- 字符型字面常量

  ```C++
  int main(){  //单引号包裹，只能有一个字符
   'c';
   'a';
   'b';
  }
  ```

- 字符串字面常量

  ```C++
  int mian(){  //双引号包裹，可以有多个字符
  	"Stone";
  	"Love";
  }
  ```
