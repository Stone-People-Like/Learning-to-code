## 使用方式

- 按下面的阶段顺序推进，每道题都用 **Go** 写
- 状态标记：⬜ 未开始 / 🟨 进行中 / ✅ 已通过 / ⭐ 已通过且自己满意
- 卡住时把题目链接和你的代码一起发出来讨论
- 代码统一写在仓库根目录的 `luogu-go/<题号>/main.go`，用 `go run ./<题号>` 调试，通过后提交洛谷
- 所有题目骨架已生成好，直接打开对应文件写实现即可

## Go 刷题重点提示

| 题单 | Go 特有坑点 |
|------|------------|
| 顺序结构 | `fmt.Println` / `fmt.Printf` 格式化；`fmt.Scan` 带空格会截断 |
| 分支结构 | `if` 必须带大括号；`switch` 不需要 break，默认不穿透 |
| 循环结构 | 只有 `for` 一种循环；`for i := 0; i < n; i++` |
| 数组 | 固定数组 `[n]T` vs 切片 `[]T`；切片要 `make` |
| 字符串 | `string` 不可变；按字节索引，中文要用 `[]rune` |
| 函数与结构体 | 多返回值天然适合；`struct` + 方法接收者 |
| 大数 | Go 没有内置大整数运算类型，高精度手写切片 |
| 排序 | `sort.Slice` + `less` 闭包，注意 int 溢出 |
| 集合/图 | `map[T]bool` 当 set；邻接表用 `[][]int` |
| 数学 | `int` 是 64 位，但乘法要注意溢出；必要时用 `int64` |

## 输入模板

```go
package main

import (
	"bufio"
	"fmt"
	"os"
)

var in = bufio.NewReader(os.Stdin)
var out = bufio.NewWriter(os.Stdout)

func main() {
	defer out.Flush()
	var n int
	fmt.Fscan(in, &n)
	// ...
}
```
